# Plain: unprotected local simulation variant

**Plain** is the bare-bones RISCue variant. `PIPELINE_PROTECTION=PLAIN` selects mode 2. Use `make pipeline-smoke pipeline-jump PIPELINE_PROTECTION=PLAIN` or the mandatory development gate `make pipeline-variants-check`.

The shared engine uses one pipeline/architectural state copy, raw register words, one jump/execute/multiply-divide lane, no voting, parity replay, ECC correction or scrubbing. Multiply/divide uses one state record. RF_TMR and fault injection must be disabled. Unused replica records are constant and their preservation attributes are disabled. Existing bus ports retain their 39-bit width for source compatibility; PLAIN carries zero-extended raw 32-bit words, not SECDED codewords.

The local-memory SoC plain branch uses ordinary 32-bit RAM and one response handshake, without the protected event monitor. RISCUE_PLAIN_MEMORY is generated by the canonical Make/Python configuration for PLAIN; this is a local simulation integration, not an unprotected FPGA/AXI/packet target. Direct instantiation of the core supports numeric mode 2. Existing protected integration defaults stay TMR.

All three variants share functional pipeline logic. The required gate builds sequentially because existing simulation targets share output paths, and saves logs plus source provenance in build/variant-matrix. Smoke covers multiply/divide, loads/stores, forwarding, compressed instructions, CSRs and trap return. Jump tests cover early/late redirects and precise traps. Protected replay fault tests remain required. These directed tests do not establish complete ISA equivalence or physical resource/timing results.
