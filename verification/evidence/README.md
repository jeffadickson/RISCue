# Verification evidence

These are historical development records, including the v0.1/v0.2 simulations and partial v0.3 formal work. They are not a new test run or complete formal signoff. Large JSON/XML/log records are stored as gzip archives; decompress them with `gzip -dk file.gz` or Python gzip. Compression preserves the original bytes.

`formal/RUN_STATUS.md` identifies completed versus interrupted campaigns and unresolved proof obligations. Raw original-model counterexamples document the signed DIV/REM model issue described in `docs/FORMAL.md`.
